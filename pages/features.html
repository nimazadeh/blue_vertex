۰1 · API نسخه‌بندی‌شده

API نسخه‌بندی‌شده

یک API مدرن با نسخه‌بندی شفاف (v1)، محدودیت نرخ هر Endpoint و کدهای خطای معنادار. نمونه‌کد خودکار برای پنج زبان.

  • نسخه‌بندی semver با سازگاری عقب‌رو
  • محدودیت نرخ و سهمیه‌بندی شفاف
  • خطاهای فارسی با کد، پیام و راهنمای رفع
مشاهده در مرجع API
bash
curl https://api.bluevertex.ir/v1/users \
  -H "Authorization: Bearer $BV_KEY" \
  -d '{"name":"سارا احمدی","email":"sara@abrino.ir"}'
۰2 · امنیت سازمانی

امنیت سازمانی

TLS 1.3 در همه ارتباطات، رمزنگاری AES-256 در حالت سکون و گزارش ممیزی کامل برای هر تغییر حساس.

  • کلیدهای دارای Scopes و تاریخ انقضا
  • تشخیص فعالیت غیرعادی و هشدار آنی
  • مطابق با اصول SOC 2 و ISO 27001

۰3 · احراز هویت

احراز هویت

از کلید API ساده تا OAuth 2.0 کامل. چرخش کلید بدون قطعی، نشست‌های امن و ورود دومرحله‌ای برای تیم شما.

  • API Key ،OAuth 2.0 و JWT
  • چرخش کلید با دوره هم‌پوشانی
  • ورود دومرحله‌ای TOTP

۰4 · Webhookهای قابل‌اعتماد

Webhookهای قابل‌اعتماد

تحویل تضمینی رویدادها با تلاش مجدد تصاعدی، امضای HMAC و مشاهده تاریخچه تحویل در داشبورد.

  • امضای HMAC-SHA256 و چرخش کلید امضا
  • صف داخلی با تضمین at-least-once
  • تست Webhook با ارسال نمونه
