## ۲. رفتار نقاط شکست

### < 1024px
- ناوبری اصلی → منوی کشویی موبایل (پنل از سمت راست در RTL، با `translateX(100%)`).
- سایدبار داشبورد → دراور ثابت با backdrop؛ دکمه `side-toggle` در نوار بالا.
- `feature-row` ها تک‌ستونه؛ `window-body` تک‌ستونه؛ گریدهای قیمت ۲→۱ ستونه.

### < 768px
- کارت‌های قیمت/وبلاگ/بازخورد تک‌ستونه.
- فوتر ۲ ستونه؛ هدر فوتر تمام‌عرض.
- پدینگ پایین داشبورد +۹۶px (جای نوار ناوبری پایین موبایل).

### جستجو و پالت در موبایل
- کادر جستجوی نوار بالا در موبایل مخفی و از طریق آیکون/فرمان قابل دسترس است؛ `topbar-search` با آیکون جایگزین می‌شود.

## ۳. جزئیات RTL

### ساختار
- `<html lang="fa" dir="rtl">` روی هر ۴۰ صفحه (تأیید qa.py + audit).
- موقعیت سایدبار داشبورد و مستندات: **راست** صفحه (ستون اول در RTL)؛ محتوا در چپِ آن.
- منوی موبایل از راست باز می‌شود؛ فلش‌های «بازگشت/بعدی» آینه شده‌اند.

### CSS منطقی (نمونه‌های استفاده‌شده)
```css
inset-inline-start / inset-inline-end   /* سایدبار، منوها، نشان‌ها */
margin-inline / padding-inline          /* کانتینرها، لیست‌ها */
border-inline-end                       /* جداکننده سایدبار و جدول‌ها */
text-align: start                       /* متن‌ها */
transform: translateX(±100%)            /* فقط برای منوها با [dir="rtl"] override */
```
جستجوی `left|right` در CSS: فقط در `transform` های عمدی منوها و `50%` مرکز‌سازی‌ها — هیچ `left`/`right` برای چیدمان جریان استفاده نشده است.

### جزیره‌های LTR (محتوای فنی)
| نوع محتوا | کلاس/روش |
|---|---|
| URL و endpoint | `direction:ltr; unicode-bidi:isolate` |
| بلوک کد (`pre>code`) | `direction:ltr; text-align:left` داخل `.code-window` |
| متد HTTP | `.method` با `direction:ltr` + `uppercase` |
| کلید API (`bv_live_…`) | `code.inline` با `direction:ltr` |
| ایمیل/شماره موبایل | `.input.ltr` |
| نسخه‌ها (2.4.1) و کدها (200) | isolation خودکار + `tabular-nums` |

### اعداد و تاریخ در RTL
- ۱۲۴٬۵۸۰ / ۹۹٫۹۸٪ / ۳٬۹۰۰٬۰۰۰ تومان — با `Intl.NumberFormat('fa-IR')` (گروه‌بندی و جداکننده درست).
- تاریخ: «یکشنبه، ۸ شهریور ۱۴۰۵» — الگوریتم جلالی (تست زنده: بدون خطا).
- سال بدون جداکننده هزارگان («۱۴۰۵» نه «۱٬۴۰۵»).

## ۴. مشکلات یافت‌شده و رفع (خلاصه)

| عرض | مشکل | ریشه | رفع |
|---|---|---|---|
| ۳۹۰px | سرریز ۱۱۶px در صفحه اصلی | `1fr` بدون `min-width:0` | `min-width:0` روی آیتم‌های گرید |
| ۳۹۰px | سرریز ۴۵۲px در قیمت‌گذاری | استایل اینلاین ۴ ستونه | حذف اینلاین + کلاس ریسپانسیو |
| ۳۹۰px | سرریز ۴۳۳px در امکانات | همان `min-width` | همان اصلاح |
| ۱۴۴۰px | محتوای داشبورد زیر صفحه | گرید سایدبار ۱۰۰vh | ردیف ثابت ۶۴px + `grid-row:1/-1` |
| ۱۴۴۰px | ستون خالی ۴۲۰px در API | TOC مخفی ولی ستون‌بندی سه‌ستونه | `api-shell-notoc` |

**پس از اصلاحات: ۴۰/۴۰ صفحه در همه عرض‌ها بدون سرریز — ۰ خطای کنسول در مرورگر واقعی.**
