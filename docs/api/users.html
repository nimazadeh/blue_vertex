کاربران

منبع users برای مدیریت کاربران نهایی محصول شماست — نه اعضای تیم. برای هر کاربر، مواردی مثل شناسه، نقش و تاریخ ثبت ذخیره می‌شود.

نسخه v1 · آخرین به‌روزرسانی: ۲۸ مرداد ۱۴۰۵

  "id": "usr_8f2k1",

  "email": "sara@abrino.ir",
  "role": "developer",

typescript
interface User {
  id: string;
  name: string;
  email: string;
  role: 'developer' | 'admin' | 'viewer';
  status: 'active' | 'suspended';
  created_at: string;
}

#لیست کاربران

GET/v1/users

فهرست همه کاربران با فیلتر و صفحه‌بندی.

پارامترنوعوضعیتتوضیح
pagenumberاختیاریشماره صفحه — پیش‌فرض ۱
limitnumberاختیاریتعداد در هر صفحه، حداکثر ۱۰۰ — پیش‌فرض ۲۰
roleenumاختیاریفیلتر نقش: developer | admin | viewer
statusenumاختیاریفیلتر وضعیت: active | suspended
searchstringاختیاریجستجوی نام یا ایمیل (حداقل ۲ کاراکتر)
نکته

فیلترها با هم ترکیب می‌شوند (AND). برای جستجوی پیشرفته از پارامتر search استفاده کنید.

#ساخت کاربر

POST/v1/users

یک کاربر جدید می‌سازد و آن را با کد 201 برمی‌گرداند.

پارامترنوعوضعیتتوضیح
namestringالزامینام کامل کاربر — ۲ تا ۱۲۰ کاراکتر
emailemailالزامیایمیل یکتا — در صورت تکرار خطای already_exists
roleenumاختیارینقش کاربر — پیش‌فرض developer
metadataobjectاختیاریداده دلخواه (JSON) تا ۱۰ کیلوبایت

#دریافت کاربر

GET/v1/users/{id}

جزئیات یک کاربر بر اساس شناسه. اگر کاربر وجود نداشته باشد 404 برمی‌گردد.

#ویرایش کاربر

PATCH/v1/users/{id}

ویرایش جزئی: فقط فیلدهای ارسال‌شده تغییر می‌کنند. برای تغییر ایمیل، ایمیل جدید باید یکتا باشد.

#حذف کاربر

DELETE/v1/users/{id}

به‌صورت نرم حذف می‌کند؛ کاربر به وضعیت deleted می‌رود و دیگر در لیست‌ها نمی‌آید. این عملیات قابل بازگشت نیست.

هشدار

حذف کاربر قابل بازگشت نیست. ابتدا با status=suspended کاربر را معلق کنید و پس از بررسی، حذف نهایی کنید.
