مرجع API

پایگاه آدرس همه درخواست‌ها https://api.bluevertex.ir و نسخه فعلی v1 است. همه Endpointها به هدر Authorization: Bearer نیاز دارند.

نسخه v1 · آخرین به‌روزرسانی: ۲۹ مرداد ۱۴۰۵
GEThttps://api.bluevertex.ir/v1

نمای کلی: نسخه، وضعیت و محدودیت نرخ هنر فضای کاری.

احراز هویت: Bearerنرخ: ۶۰ در دقیقه

#صفحه‌بندی و فیلتر

همه لیست‌ها با پارامترهای page و limit (حداکثر ۱۰۰) صفحه‌بندی می‌شوند و متادیتا در meta برمی‌گردد:

cURL
curl "https://api.bluevertex.ir/v1/users?page=2&limit=25&role=developer" \
  -H "Authorization: Bearer $BV_API_KEY"
JavaScript
const { data, meta } = await bv.users.list({ page: 2, limit: 25 });
console.log(meta.total, meta.page);

#کدهای وضعیت

کدناموضعیتتوضیح
200OKالزامیدرخواست موفق — بدنه داده در data
201Createdالزامیمنبع جدید ساخته شد (Endpointهای POST)
400Bad Requestالزامیورودی نامعتبر — جزئیات در error.fields
401Unauthorizedالزامیکلید نامعتبر یا غایب
403Forbiddenالزامیدسترسی Scope مجاز نیست
404Not Foundالزامیمنبع وجود ندارد
409Conflictالزامیتضاد با وضعیت فعلی (مثلاً ایمیل تکراری)
429Too Many Requestsالزامیمحدودیت نرخ — هدر Retry-After را ببینید
500Server Errorالزامیخطای داخلی — با x-request-id پیگیری کنید

#مرورگر تعاملی

در بخش Endpointهای داشبورد می‌توانید هر Endpoint را با داده نمونه آزمایش کنید — بدون نیاز به کلید واقعی.

کاربران

مشاهده کامل
GET/v1/usersلیست کاربران با فیلتر و صفحه‌بندی

GET/v1/users/{id}دریافت یک کاربر
PATCH/v1/users/{id}ویرایش جزئی کاربر
DELETE/v1/users/{id}حذف کاربر

مشاهده کامل
