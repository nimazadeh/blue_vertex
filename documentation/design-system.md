# سیستم طراحی بلو ورتکس (Design System)

> نسخه ۲٫۴٫۰ — متعلق به بلو استودیو (Blue Studio)
> این سند مرجع تصمیم‌های طراحی محصول است: توکن‌ها، تایپوگرافی، کامپوننت‌ها، حالت‌ها و اصول RTL.

---

## ۱. فلسفه طراحی

بلو ورتکس یک محصول **زیرساختی و سازمانی** است؛ بنابراین هویت بصری آن سه اصل دارد:

1. **آرام اما قدرتمند (Calm Technology):** بدون درخشش‌های نئونی، بدون گرادیان‌های پر سر و صدا؛ اعتماد با سکوت و دقت ساخته می‌شود.
2. **تیره‌ی سازمانیِ نرم‌شده:** پس‌زمینه `#0B0D12` (نه مشکی خالص) با سطوح خاکستری-سرمه‌ای و یک آبی برند که در کل محصول جریان دارد — به‌همراه **تم روشن کامل** با سطوح سفید و کنتراست WCAG AA.
3. **فارسی‌اول:** از تایپوگرافی وزیرمتن تا اعداد فارسی و تاریخ شمسی — هیچ عنصری «ترجمه‌ی» یک محصول خارجی نیست.

**محیط‌های خصمانه:** تبلت/موبایل ۳۲۰px، دسکتاپ ۱۴۴۰px و اولترا واید ۱۹۲۰px — همه با هم تست شده‌اند (گزارش ریسپانسیو را ببینید).

## ۳. شبکه و چیدمان

- **کانتینر اصلی:** `--container: 1200px`، کانتینر عریض ناوبری: `--container-wide: 1320px`؛ پدینگ افقی ۲۴px.
- **داشبورد:** گرید `248px + minmax(0,1fr)` با ردیف ثابت ۶۴px برای نوار بالا؛ سایدبار چسبان با `grid-row: 1 / -1`.
- **مستندات:** گرید `250px + minmax(0,1fr) + 420px` (سایدبار، محتوا، فهرست مطالب)؛ صفحات API از کلاس `api-shell-notoc` با دو ستون استفاده می‌کنند.
- **نقاط شکست:** ۱۱۸۰px (گریدهای ۲ ستونه)، ۱۰۲۴px (منوی موبایل، سایدبار به دراور)، ۹۲۰px (مستندات تک‌ستونه)، ۷۶۸px (کارت‌ها تک‌ستونه)، ۴۸۰px (ریزتر).
- **قاعده ضد سرریز:** همه آیتم‌های گرید `min-width: 0` دارند تا محتوای کشیده (کد، URL بلند) هرگز عرض سند را نشکند.

## ۴. کامپوننت‌های اصلی

| کامپوننت | حالت‌ها / توجه‌ها |
|---|---|
| دکمه `.btn` | `primary` (آبی برند)، `secondary` (سطح)، `outline`، `ghost`، `danger`؛ سایز sm/md/lg؛ حالت `btn-loading` و `disabled` |
| کارت `.card` | `card-pad`، `card-hover`، `card-head/foot`؛ سایه hover ملایم + جابه‌جایی ۴- |
| فرم `.field/.input/.select` | فوکوس با `--border-focus` آبی؛ `field-error` با پیام فارسی؛ `input.ltr` برای ایمیل/شماره |
| بج `.badge` | `badge-blue/green/amber/red/violet` |
| متد HTTP `.method` | GET/POST/PUT/PATCH/DELETE با رنگ معنایی؛ `text-transform:uppercase`؛ همیشه LTR |
| جدول `.table` | هدر چسبان، hover ردیف، ستون اعداد `tabular-nums` |
| تب `.tab-btn` | `aria-selected`، پنل‌های `[data-panel]` |
| آکاردئون `.accordion` | باز شدن تکی (تک‌باز)، کیبورد Enter/Space |
| مودال `.modal-backdrop` | فوکوس خودکار اولین ورودی، بستن با ESC و کلیک بیرون |
| دراور `.drawer` | از سمت چپ در RTL (از `inset-inline`)، با `aria-modal` |
| پالت `.palette` | جستجوی سریع با پیمایش ↑↓ و Enter |
| توست `.toast` | `aria-live="polite"`؛ چهار نوع موفقیت/خطا/هشدار/اطلاع |
| Empty State | آیکون + عنوان + متن راهنما + CTA (در همه صفحات داشبورد و وبلاگ) |
| Skeleton | فقط در حالت‌های واقعاً غیرقطعی؛ هیچ «لودینگ جعلی» وجود ندارد |

**قواعد اجباری کامپوننت:**
- هیچ دکمه‌ی مرده‌ای نداریم — هر دکمه یا کاری انجام می‌دهد (دمو) یا حذف شده است.
- هیچ placeholder متنی (`TODO`/`به‌زودی`) در هیچ صفحه‌ای وجود ندارد — توسط گیت QA بررسی می‌شود.
- هر form دارای فیلد `novalidate` + اعتبارسنجی جاوااسکریپتی با پیام فارسی است (از اعتبارسنجی پیش‌فرض مرورگر با متن لاتین استفاده نمی‌شود).

## ۵. اصول RTL (معماری، نه افزونه)

1. `<html lang="fa" dir="rtl">` روی همه ۴۰ صفحه؛ سند در RTL ساخته می‌شود.
2. **CSS منطقی:** `inset-inline-start/end`، `margin-inline`، `padding-inline`، `border-inline-end`، `text-align: start` — جستجوی grep نشان می‌دهد هیچ `left/right` سخت‌کد شده‌ای در استایل‌های جریان وجود ندارد (فقط در transform های عمدی منوها).
3. **جزیره‌های LTR:** کلاس/سبک `direction:ltr; unicode-bidi:isolate` روی: URLها، endpointها، بلوک‌های کد (`pre`)، متدهای HTTP، کلیدهای API (`bv_live_…`)، ایمیل‌ها، نسخه‌ها، دستورات Git و جدول‌های فنی.
4. **آیکون‌های جهت‌دار:** آیکون‌های «بعدی/قبلی» در RTL آینه شده‌اند (`arrow-left` برای «ادامه»، `chevron-left` برای «بازگشت» در نان‌برید).
5. **اعداد:** `font-feature-settings` و `font-variant-numeric: tabular-nums` برای تراز ستون‌های عددی.
6. **اسکرول‌بار:** در حالت راست‌به‌چپ، اسکرول افقی جداول در سمت درست (شروع) قرار می‌گیرد.

## ۸. دسترس‌پذیری (خلاصه)

- کنتراست متن ≥ 4.5:1 (AA) برای متن عادی و ≥ 3:1 برای متن درشت/آیکون.
- سلسله‌مراتب h1→h6 بدون پرش (بررسی خودکار: ۰ خطا).
- `aria-label` فارسی برای تمام دکمه‌های آیکونی؛ `for/id` برای همه ورودی‌ها (۰ ورودی بدون برچسب).
- `aria-live` روی توست‌ها و منطقه اعلان؛ `role="dialog" aria-modal` روی همه مودال/دراورها؛ ESC همه‌جا بسته می‌شود.
- تصاویر: ۰ تصویر بدون `alt` (همه آیکون‌ها SVG داخلی‌اند).
- `prefers-reduced-motion` محترم شمرده می‌شود (reveal ها غیرفعال می‌شوند).
